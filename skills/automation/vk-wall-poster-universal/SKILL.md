# Universal VK Wall Poster Skill (Agent-Driven Edition)

Универсальный, кроссплатформенный навык для AI-агентов (Hermes, Claude Code, Antigravity, OpenCode, Cursor) для публикации постов, новостей и медиа в любые группы и на стены ВКонтакте.

---

## 🤖 Протокол первого запуска для ИИ-Агента (Interactive Agent Onboarding)

Когда агент выполняет задачу по публикации в ВК в первый раз:

### Шаг 1. Агент проводит быструю неблокирующую диагностику:
```bash
python scripts/vk_wall_poster.py --check --target <имя_или_id_группы>
```

### Шаг 2. Интерактивный диалог агента с пользователем в чате:
1. **Если статус `[+] ПОЛНОСТЬЮ ГОТОВ К РАБОТЕ` (активен CDP или токен в .env)**:
   - Агент сразу сообщает пользователю, что всё готово, показывает текст поста и запрашивает подтверждение («публикуем?»).

2. **Если токенов в `.env` нет и браузер не запущен**:
   - Агент **вежливо спрашивает пользователя в чате**:
     > «Для публикации в ВКонтакте мы можем использовать один из двух вариантов:
     > 1. **Через ваш открытый браузер (Chrome / Yandex / Vivaldi / Edge)** — не требует ввода ключей, мы просто подхватим вашу сессию (рекомендуется).
     > 2. **Через бессрочный API-ключ сообщества (.env)** — я помогу выпустить его в настройках группы.
     > Какой вариант предпочитаете?»

3. **Если пользователь выбирает браузер (или отказывается создавать ключ сообщества)**:
   - Агент **автоматически применяет CDP-fallback**:
     - Просит пользователя открыть VK в браузере (если браузер ещё не открыт).
     - Выполняет публикацию через CDP без единого ручного токена!

4. **Если пользователь хочет настроить Community Token**:
   - Агент пошагово объясняет в чате, как нажать *Управление → Работа с API → Создать ключ (wall, photos)*.
   - Пользователь присылает ключ в чат → агент сам записывает `VK_COMMUNITY_TOKEN` и `VK_GROUP_ID` в файл `.env`.

## ⚠️ Правила безопасности (Safety First)

1. Публикация идёт на реальную стену сообщества. **НЕ запускайте публикацию без предварительного согласования текста и явного подтверждения пользователя** («ок», «да», «публикуй»).
2. Для тестовых прогонов всегда используйте флаг проверки `--check` или отложенную публикацию (`--delay 1h`).

## 💻 Команды CLI (100% неблокирующие для агента)

Скрипт: `scripts/vk_wall_poster.py`

### 1. Проверка готовности (Dry Run):
```bash
python scripts/vk_wall_poster.py --check --target glfire_streamer
```

### 2. Публикация новости:
```bash
# Текст строкой
python scripts/vk_wall_poster.py --target glfire_streamer --text "🎮 Текст новости..."

# Текст из файла
python scripts/vk_wall_poster.py --target glfire_streamer --file "digest.txt"
```

### 3. Публикация с изображением (обложкой):
```bash
python scripts/vk_wall_poster.py --target glfire_streamer --file "digest.txt" --photo "cover.jpg"
```

### 4. Отложенный пост (через 1 час):
```bash
python scripts/vk_wall_poster.py --target glfire_streamer --file "digest.txt" --photo "cover.jpg" --delay 1h
```

## ⚙️ Справка по аргументам CLI

```text
  --check               Провести неблокирующую диагностику окружения и прав.
  --target TARGET       Группа (screen_name, ID, URL) или ID пользователя.
  --text TEXT           Текст публикации строкой.
  --file FILE           Путь к файлу с текстом публикации.
  --photo PHOTO [...]   Прикрепление до 10 изображений (JPG/PNG).
  --delay DELAY         Относительная задержка ('15m', '1h', '24h').
  --publish-date INT    Unix-таймстамп отложенной публикации.
  --as-user             Опубликовать от имени пользователя (по умолчанию: от группы).
  --token TOKEN         Прямой токен доступа (Community Token или User Token).
  --port PORT           Порт CDP браузера (по умолчанию: 9223).
```
