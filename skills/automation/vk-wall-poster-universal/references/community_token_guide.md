# Руководство: Выпуск и настройка Community Token (Ключа сообщества ВК)

**Ключ доступа сообщества (Community Token)** — это официальный, бессрочный токен ВКонтакте, создаваемый администратором группы для автоматизации публикаций.

---

## 🎯 Преимущества Community Token

* 🟢 **Бессрочный**: не сгорает через 24 часа.
* 🟢 **Автономный**: работает на любых серверах, в Docker-контейнерах и CLI без запущенного браузера.
* 🟢 **Безопасный**: имеет доступ только к указанной группе.

---

## 📋 Пошаговая инструкция по получению ключа

1. Откройте сообщество ВКонтакте, в котором вы являетесь администратором или владельцем.
2. В правом меню выберите: **«Управление»** (⚙️).
3. Перейдите во вкладку: **«Работа с API»** → **«Ключи доступа»**.
4. Нажмите синюю кнопку **«Создать ключ»**.
5. В открывшемся окне отметьте галочками права:
   - ✅ **Разрешить приложению доступ к записям на стене** (`wall`)
   - ✅ **Разрешить приложению доступ к фотографиям** (`photos`)
   - *(Опционально)* Управление сообществом (`messages`, `manage`)
6. Подтвердите создание ключа через SMS / VK ID / звонок.
7. Скопируйте строку ключа доступа вида `vk1.a.xxxx...`.

---

## ⚙️ Настройка скилла

### Вариант 1: Через файл `.env` в корне проекта

Создайте или отредактируйте файл `.env`:

```env
VK_GROUP_ID=123456789
VK_COMMUNITY_TOKEN=vk1.a.ваш_скопированный_ключ_доступа
```

### Вариант 2: Передача напрямую в CLI

```bash
python scripts/vk_wall_poster.py --token "vk1.a.xxx..." --target your_group_name --text "Тестовый пост"
```
