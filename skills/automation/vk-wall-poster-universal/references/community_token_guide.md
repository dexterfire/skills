# 🔑 Полное руководство: Выпуск и использование ключа доступа сообщества (Community Token) в VK

Ключ доступа сообщества (**Community Token**) — это официальный бессрочный API-токен ВКонтакте, позволяющий ботам и скриптам публиковать записи на стене от имени группы, управлять комментариями и отвечать в сообщениях сообщества.

---

## 🌟 Преимущества Community Token

1. **Бессрочный срок действия (Never Expires)**: В отличие от пользовательских токенов (живущих 1 час), ключ сообщества не протухает.
2. **Нет привязки к IP-адресу**: Работает на удаленных серверах (Linux VPS, Docker, CI/CD, GitHub Actions) без ошибок `error 5:1130`.
3. **Безопасность**: Токен даёт доступ только к конкретному сообществу, а не ко всему личному профилю пользователя.
4. **Не требует запущенного браузера**: Запросы отправляются напрямую через обычный HTTP POST (`curl`, `requests`).

## 🛠️ Пошаговая инструкция: Как выпустить ключ доступа

> **Требование**: Вы должны быть создателем или администратором группы/паблика.

### Шаг 1. Перейдите в настройки группы
1. Откройте ВКонтакте и зайдите в вашу группу (например, `https://vk.ru/glfire_streamer`).
2. В правом боковом меню нажмите кнопку **«Управление»** (или значок шестерёнки).

### Шаг 2. Раздел «Работа с API»
1. В меню управления перейдите во вкладку **«Работа с API»**.
2. Откройте раздел **«Ключи доступа»** (Access Tokens).

### Шаг 3. Создание ключа
1. Нажмите кнопку **«Создать ключ»**.
2. В появившемся окне отметьте права доступа:
   - ✅ **Разрешить приложению доступ к стене сообщества** (`wall`) — для публикации постов.
   - ✅ **Разрешить приложению доступ к фотографиям сообщества** (`photos`) — для работы с медиа.
   - ▫️ *Сообщения сообщества (`messages`) — отметьте, если бот будет общаться в ЛС группы.*
3. Нажмите **«Создать»**.

### Шаг 4. Подтверждение и сохранение
1. Подтвердите действие через VK ID (push-уведомление на телефоне или SMS-код).
2. **СКОПИРУЙТЕ КЛЮЧ**: ВКонтакте показывает ключ **только один раз**.
   *Ключ выглядит как длинная строка:* `vk1.a.xxxx...`

## 📝 Как прописать ключ в проект

### Способ 1. Через мастер настройки (автоматически):
```bash
python scripts/vk_wall_poster.py --setup
```
Выберите вариант `[2]`, введите ID группы и вставьте ключ. Скрипт сам создаст `.env` и проверит соединение.

### Способ 2. В файле `.env` (вручную):
Создайте или откройте файл `.env` в корне проекта и добавьте строки:
```env
VK_GROUP_ID=137821447
VK_COMMUNITY_TOKEN=vk1.a.ВАШ_СКОПИРОВАННЫЙ_КЛЮЧ_СООБЩЕСТВА
```

### Способ 3. Передача аргументом CLI:
```bash
python scripts/vk_wall_poster.py --token "vk1.a.xxx..." --target glfire_streamer --text "Тест"
```

## 🔍 Нюансы и ограничения VK API для ключей сообщества

| Метод API | Поддержка Community Token | Комментарий |
| :--- | :---: | :--- |
| `wall.post` (текст, ссылки) |  **ДА** | Публикация от имени сообщества (`from_group=1`, `owner_id=-ID`) |
| `photos.getWallUploadServer` | ⚠️ **Ограничение VK** | VK блокирует этот метод для ключей групп (*Error 27*). Наш скилл `vk-wall-poster` решает это в **гибридном режиме**: загрузка фото выполняется через сессию браузера CDP, а постинг — через Community Token! |
| `wall.edit` / `wall.delete` |  **ДА** | Управление своими записями |
| `groups.getById` |  **ДА** | Получение информации о сообществе |
| `utils.resolveScreenName` |  **ДА** | Разрешение коротких имен (glfire_streamer → 137821447) |
